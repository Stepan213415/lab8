# Лабораторна робота №8 — MVC, пошук, автентифікація й авторизація

**Тема:** MVC-архітектура, пошук та автентифікація/авторизація.  
**Предметна область:** конденсатори (на основі лабораторної №7).  
**Технології:** PHP 8.1+, MySQL/MariaDB, PDO, HTML/CSS, сесії.

> У методичці №8 використано рюкзаки та SQLite, але реальний проєкт №7 з GitHub `Stepan213415/lab7_` побудований для конденсаторів і MySQL. Цей проєкт пристосовано до **твого реального варіанту**. Назви `capacitors_db`, `capacitor_types`, `capacitors`, `parameters` і їхні поля залишені як у №7. Старі дані не видаляються.

## 1. Що вже реалізовано

1. **MVC:** `src/Models` містить моделі та PDO-репозиторії, `src/Views` відповідає за HTML, `src/Controllers` обробляє запити.
2. **Front Controller:** єдина точка входу `public/index.php`.
3. **Router:** `src/Router.php` обробляє GET/POST-адреси.
4. **Пошук за SQL LIKE через параметризовані запити:** `/capacitors?q=...` (позначення), `/types?q=...` (назва типу), `/parameters?q=...` (назва/значення/позначення конденсатора).
5. **Реєстрація та вхід:** нова таблиця `users`, `password_hash()`, `password_verify()`, PHP-сесії, `session_regenerate_id()`.
6. **Авторизація:** анонім може лише переглядати та шукати; авторизований користувач може додавати, редагувати, видаляти, завантажувати фотографії, додавати параметри й типи.
7. **Фотографії:** JPG/PNG/WEBP до 2 МБ із перевіркою MIME та випадковим ім'ям файлу.
8. **Базовий захист форм:** CSRF-токени та екранування HTML у шаблонах.

## 2. Запуск на Windows через XAMPP

### Крок 1 — розпакуй ZIP

Розпакуй увесь архів у папку, наприклад:

`C:\xampp\htdocs\lab8_mvc_capacitors`

У цій папці мають бути `bootstrap.php`, `public`, `src`, `database`, `README.md`.

### Крок 2 — запусти MySQL

Відкрий **XAMPP Control Panel** та натисни **Start** біля **MySQL**. Apache для способу нижче запускати необов'язково.

Відкрий `http://localhost/phpmyadmin/` (для цього XAMPP Apache має бути запущений) або скористайся іншою програмою для роботи з MySQL.

### Крок 3 — налаштуй БД

**Якщо у тебе вже є `capacitors_db` із лабораторної №7:**

1. Відкрий `capacitors_db` у phpMyAdmin.
2. Перейди на вкладку **Імпорт**.
3. Вибери `database/migrate_lab8.sql` та натисни **Імпорт**.
4. Це створить **лише таблицю `users`**; решта записів залишиться без змін.

**Якщо база ще не створена:**

1. У phpMyAdmin імпортуй файл `database/schema.sql` (він створює базу й усі таблиці).
2. За бажанням імпортуй `database/demo_data.sql`, щоб одразу з'явилися тестові конденсатори.

**Важливо:** не імпортуй старий `schema.sql` з лабораторної №7 у наявну заповнену базу: там є `DROP TABLE`, через які можна видалити дані. Використовуй доданий тут `migrate_lab8.sql`.

### Крок 4 — перевір доступ до MySQL

Типові параметри XAMPP уже вписані в `bootstrap.php`:

- сервер: `127.0.0.1`
- база: `capacitors_db`
- користувач: `root`
- пароль: порожній
- порт: `3306`

Якщо у MySQL інший пароль або порт, установи змінні оточення `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD` (або відредагуй значення за замовчуванням у `bootstrap.php`). Потрібен PHP-модуль `pdo_mysql`.

### Крок 5 — запусти PHP-сервер

Відкрий **PowerShell** у папці проєкту (у Провіднику введи `powershell` у рядку шляху). Введи:

```powershell
& "C:\xampp\php\php.exe" -S localhost:8000 -t public public/router.php
```

Якщо `php` доданий до PATH, можна коротше:

```powershell
php -S localhost:8000 -t public public/router.php
```

Залиш консоль відкритою й перейди у браузері на:

**http://localhost:8000**

> Якщо порт 8000 зайнятий, заміни в команді на 8001 і відкрий `http://localhost:8001`.

### Крок 6 — перенеси старі фото (якщо вони були)

У старій №7 фото лежали в папці `uploads/` поряд з `api.php`.

Скопіюй **вміст** старої папки `uploads` до `public/uploads` у новому проєкті. Інакше старі записи залишаться в БД, але їхні фотографії не відображатимуться.

## 3. Як перевірити виконання завдання

1. **Без входу:** зайди на `/capacitors`. Переконайся, що список відкривається, кнопки редагування/додавання не показуються. Зроби **скриншот №1**.
2. **Форма входу:** зайди на `/login`. Зроби **скриншот №2**.
3. **Реєстрація:** зайди на `/register`, створи користувача (наприклад, `student8` та власний пароль), повернися на `/login` і увійди.
4. **Після входу:** відкрий `/capacitors`, перевір появу кнопки **+ Додати конденсатор** та логіна в меню. Зроби **скриншот №3**.
5. **Пошук:** на `/capacitors` введи частину існуючого позначення. Наприклад, для демоданих пошук `К50` поверне `К50-35`. Зроби **скриншот №4**. Перевір пошук на `/types` та `/parameters`.
6. **Додавання:** натисни **+ Додати конденсатор**, вибери тип, введи позначення/ємність/напругу, збережи.
7. **Фото й параметри:** відкрий створений запис, додай JPG/PNG/WEBP та параметр, перевір їхнє відображення.
8. **Редагування/видалення:** відредагуй дані та перевір збереження. За необхідності видали власний тестовий запис.
9. **Безпека:** натисни **Вийти**. Якщо знову відкрити `/capacitors/create`, застосунок має перенаправити на `/login`.
10. **Перевір хеш:** у phpMyAdmin відкрий таблицю `users` і переконайся, що в `password_hash` — довгий хеш, а не введений пароль. Не публікуй скриншот реального пароля.

**Для звіту обов'язкові принаймні чотири знімки:** вхід, пошук, список до входу, список після входу — відповідно до завдання з PDF.

## 4. Основні файли та логіка MVC

```text
lab8_mvc_capacitors/
├── bootstrap.php                   # PDO + autoload + сесія + CSRF
├── database/
│   ├── schema.sql                  # повна БД для нового запуску
│   ├── migrate_lab8.sql            # тільки users для існуючої №7
│   └── demo_data.sql               # необов'язкові приклади
├── public/
│   ├── index.php                   # Front Controller + маршрути
│   ├── router.php                  # запуск через php -S
│   ├── assets/style.css
│   └── uploads/                    # фотографії
├── src/
│   ├── Router.php
│   ├── Auth.php
│   ├── Controllers/                # контролери
│   ├── Models/                     # моделі й репозиторії
│   └── Views/                      # HTML-шаблони
├── tests/smoke.php
└── REPORT_TEXT.md                  # текст для звіту
```

**Приклад повного циклу:** GET `/capacitors?q=К50` → `Router` → `CapacitorController::index()` → `CapacitorRepository::findAll('К50')` → MySQL `LIKE :q` → `Views/capacitors/index.php`.

## 5. Контрольні питання (коротко)

1. **MVC:** Model працює з даними й правилами, View їх показує, Controller обробляє запити та координує обидві частини.
2. **Front Controller:** одна PHP-точка входу, через яку проходять запити й вибираються маршрути.
3. **spl_autoload_register():** автоматично підключає файли класів за простором імен замість багатьох `require`.
4. **LIKE та prepared statements:** параметри запиту передаються окремо від SQL, що запобігає SQL-ін'єкціям.
5. **Автентифікація / авторизація:** перша підтверджує користувача, друга перевіряє його права.
6. **session_regenerate_id():** міняє ідентифікатор сесії після входу, щоб знизити ризик фіксації сесії.
7. **Хеш пароля:** незворотне представлення дозволяє перевіряти пароль без його збереження у відкритому вигляді.

## 6. Діагностика помилок

- **`could not find driver`:** у `php.ini` ввімкни `extension=pdo_mysql` (за потреби також `extension=mysqli`); перезапусти сервер PHP.
- **`SQLSTATE[HY000] [1049] Unknown database`:** імпортуй `database/schema.sql` або перевір `DB_NAME`.
- **`Access denied for user 'root'`:** зміни користувача/пароль у змінних оточення або `bootstrap.php`.
- **`404` на всіх маршрутах:** запускай саме з `public/router.php`, як у команді вище, а не відкривай PHP-файли подвійним кліком.
- **Зображення зі старої №7 не видно:** скопіюй попередню папку `uploads/` у `public/uploads/`.
- **`Failed to open stream` / помилки сесії:** перевір, що ZIP розпаковано повністю й структура папок збережена.

**Примітка про перевірку:** PHP-файли можна перевірити синтаксично командою `php -l`. Для повної функціональної перевірки потрібен запущений MySQL із таблицями; він працює на твоєму комп'ютері, не в цьому архіві.
